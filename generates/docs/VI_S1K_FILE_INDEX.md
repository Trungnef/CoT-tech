# Vi-S1K System - File Index & Reference Guide

## 📑 Complete File Listing

### 🔧 Core Implementation Files

#### 1. **llm_evaluation/utils/translation_utils.py**
**Purpose**: Translation engines and utilities for converting text between languages
**Key Classes**:
- `TranslationCache`: File-based caching system for translated text
- `TranslationPromptBuilder`: Creates various prompt templates for translation
- `MultilingualTranslator`: Base class for all translators
- `GeminiTranslator`: Google Gemini API translator
- `OpenAITranslator`: OpenAI API translator
- `LocalLLMTranslator`: Local LLM model translator
**Size**: ~400 lines
**Dependencies**: google-generativeai, openai, transformers, torch

#### 2. **generates/s1k_translator.py**
**Purpose**: S1K dataset loading and Vietnamese benchmark creation
**Key Classes**:
- `TranslatedQuestion`: Dataclass for translated questions
- `S1KDatasetLoader`: Loads S1K dataset from Hugging Face
- `VietnameseBenchmarkBuilder`: Main builder for Vi-S1K
- `QualityChecker`: Quality assessment for translations
**Size**: ~450 lines
**Dependencies**: datasets, dataclasses, pathlib

#### 3. **generates/vi_s1k_builder.py**
**Purpose**: Main command-line interface for building Vi-S1K
**Key Components**:
- Argument parsing
- Workflow orchestration
- Progress reporting
- Statistics display
**Size**: ~200 lines
**Usage**: `python generates/vi_s1k_builder.py [options]`
**Main Options**:
- `--translator {gemini,openai,local}`
- `--max-samples N`
- `--output-dir PATH`
- `--formats FORMAT1 FORMAT2`
- `--test-run`

#### 4. **generates/vi_s1k_config.py**
**Purpose**: Configuration management for Vi-S1K system
**Key Classes**:
- `TranslatorConfig`: Translator configuration
- `DatasetConfig`: Dataset configuration
- `QualityConfig`: Quality control configuration
- `OutputConfig`: Output format configuration
- `PromptConfig`: Translation prompt templates
- `ViS1KConfig`: Main config class
**Presets**: lightweight, production, experimental, local
**Size**: ~350 lines
**Features**:
- Config file loading/saving
- Environment variable support
- Preset configurations

```

    ↓
```

```
    ↓
results/vi_s1k_evaluation/ (reports, stats)
```
